# 质感 HTML5 播放器 (Unified HTML5 Player)

质感 HTML5 网页播放器，统一主流浏览器（Edge / Chrome / Firefox / Zen / Safari / Opera）的原生播放器外观。
视频播放器采用通透无背景框悬浮设计，音频播放器配备极简轻量毛玻璃底座。
支持丰富快捷键（无级倍速/逐帧微调/快进快退/音量/画中画/截图/全屏/镜像翻转）、左上角高质感 OSD 屏幕提示，采用零侵入架构，精准保留原始网页布局和媒体尺寸。

- **Greasy Fork**: [https://greasyfork.org/zh-CN/scripts/554122](https://greasyfork.org/zh-CN/scripts/554122)
- **匹配网址**: `*://*/*`
- **运行策略**: `document-start`

---

### ✨ 核心特性

1. **统一全浏览器外观**：抹平 Chromium 与 Gecko/WebKit 等不同内核的原生播放器黑条与样式差异，全平台统一为精致现代的极简风格。
2. **通透无框设计**：视频控制栏彻底去除多余的厚重背景框与边框，与视频底部更紧密贴合（左右仅距 8px，底部仅距 4px），沉浸感极强；音频播放器保留轻透毛玻璃框。
3. **高质感左上角 OSD 提示**：
   - 音量调节：立体声小喇叭图标 + 蓝紫色粗体文字 `音量 45%`
   - 普通快退/快进 (5s)：蓝色渐变圆角方块图标 + 蓝紫色粗体文字 `-5s` / `+5s` + 纯白时间进度
   - 快速快退/快进 (30s)：蓝色渐变圆角方块图标 + 高亮金黄色粗体文字 `+30s (快速)` + 纯白时间进度
   - 倍速调节：时钟测速图标 + 蓝紫色/金黄色文字 `播放速度 1.5x` / `恢复正常速度 1.0x`
   - 逐帧微调：帧微调图标 + `上一帧` / `下一帧` + 精确时间进度
   - 画面截图：相机图标 + `已截图保存` + 分辨率信息
   - 画中画 / 画面镜像翻转：无痕淡入淡出反馈
4. **零侵入式架构**：
   - 绝不包裹或篡改 `<video>` / `<audio>` 在原始页面的 DOM 节点层次；
   - 100% 保持原网页的 CSS 布局、flex/grid 属性与原始媒体尺寸，杜绝变形与移位。
5. **无损真全屏机制**：
   - 全屏时采用视口置顶技术，不移动底层 DOM 节点，零断流风险；退出全屏后 100% 原位无痕恢复。
6. **智能输入框防误触**：在网页搜索框、评论区、编辑器打字时，自动禁用所有播放器快捷键。

### 🎮 快捷键操作指南

| 功能类别 | 快捷键 / 鼠标动作 | 左上角 OSD 提示说明 |
| :--- | :--- | :--- |
| **快进 / 快退** | `←` / `→` | 微调后退 / 前进 5 秒 (`-5s` / `+5s`，蓝紫色粗体) |
| **快速快进 / 快退** | `Shift + ←` / `→`<br>`Ctrl + ←` / `→` | 快速后退 / 前进 30 秒 (`±30s (快速)`，金黄高亮粗体) |
| **倍速调节** | `C` / `X` | 播放速度 ±0.1x 无级微调 (0.1x ~ 16x) |
| **重置倍速** | `Z` | 恢复正常速度 1.0x |
| **逐帧微调** | `D` / `F` | 上一帧 / 下一帧 (约 0.033s，寻找最佳截图点) |
| **画面截图** | `Shift + S` | 截取视频当前帧并无损下载为 PNG |
| **画中画模式** | `Shift + P` | 开启 / 退出浏览器原生画中画小窗 |
| **画面水平镜像** | `Shift + M` | 画面左右镜像翻转 (舞蹈/健身/镜像教学视频神器) |
| **音量微调** | `↑` / `↓`<br>画面滚轮滑动 | 音量调节 ±5% (`🔊 音量 XX%`) |
| **音量快速调节** | `Ctrl + ↑` / `↓` | 音量调节 ±20% |
| **静音切换** | `M` 键 / 点击喇叭 | `🔇 静音` / `🔊 音量 XX%` |
| **播放 / 暂停** | `Space`（空格）/ 画面单击 | `▶ 播放` / `⏸ 暂停` (带双击防抖解耦) |
| **无损全屏** | `Enter` / 画面双击 | 切换无损全屏模式 |
