# 质感 HTML5 播放器 (Unified HTML5 Player)

质感 HTML5 网页播放器，统一主流浏览器（Edge / Chrome / Firefox / Zen / Safari / Opera）的原生播放器外观。
视频播放器采用通透无背景框悬浮设计，音频播放器配备极简轻量毛玻璃底座。
支持丰富快捷键（S键顺时针旋转画面/无级倍速/Z键双向循环切换/逐帧微调/快进快退/音量/画中画/截图/Ctrl+C复制当前帧/全屏/镜像翻转）、左上角高质感 OSD 屏幕提示，采用零侵入架构，精准保留原始网页布局和媒体排版尺寸。

- **Greasy Fork**: [https://greasyfork.org/zh-CN/scripts/554122](https://greasyfork.org/zh-CN/scripts/554122)
- **匹配网址**: `*://*/*` 以及 `file:///*` (本地文件直接播放)
- **运行策略**: `document-start`

### ✨ 核心特性

1. **统一全浏览器外观**：抹平 Chromium 与 Gecko/WebKit 等不同内核的原生播放器黑条与样式差异，全平台统一为精致现代的极简风格。
2. **智能识别第三方播放器（零重叠）**：
   - 自动识别所有嵌套在第三方子 iframe 内的视频，以及 Jellyfin、Emby、Plex、Plyr, Video.js, DPlayer, ArtPlayer, Bilibili, YouTube 等网页自带的自定义播放器；
   - **对于自定义播放器与 iframe 嵌入页**：彻底卸载并不在 DOM 挂载自制控制栏 UI，绝不遮挡或与网页自带控制栏发生双层重叠！
   - **全局快捷键与 OSD 赋能**：虽不覆盖网页自带样式，但快捷键系统（调速、逐帧、旋转、截图、复制当前帧等）与左上角高质感 OSD 依然全局生效！
3. **通透无框视频设计**：原生视频控制栏彻底去除多余的厚重背景框与边框，与视频底部紧密贴合（左右仅距 8px，底部仅距 4px），沉浸感极强。
4. **独立原位音频排版**：音频播放器（`<audio>`）采用原位文档流轻透胶囊排版，完美兼容多音频对比网页（如语音合成、试听表格），各单元格规整对齐，绝不产生多浮层重叠与脱轨漂移。
5. **动态位置追踪引擎（专治 ComfyUI 画布脱轨）**：针对 ComfyUI 等 WebApp 的 Canvas 画布拖拽、平移、缩放（Zoom/Pan）及 CSS Transform 场景，引入帧级轻量位置监测器与全局拖拽感知，实现控制条与 OSD 如影随形、零延迟动态吸附，视口越界自动隐藏，绝不孤立残留。
6. **全能倍速记忆切换**：按 `C`/`X` 调整倍速时自动记忆，按 `Z` 键可在**自定义倍速与正常速度 1.0x 之间双向来回循环切换**。
7. **本地与直链播放接管**：全面支持本地音视频文件（`file:///...`）和网页独立媒体直链居中播放。
8. **高质感左上角 OSD 提示**：
   - 画面旋转：循环旋转图标 + `画面旋转 90°` / `180°` / `270°` / `0° (恢复)`
   - 音量调节：立体声小喇叭图标 + 蓝紫色粗体文字 `音量 45%`
   - 普通快退/快进 (5s)：蓝色渐变圆角方块图标 + 蓝紫色粗体文字 `-5s` / `+5s` + 纯白时间进度
   - 快速快退/快进 (30s)：蓝色渐变圆角方块图标 + 高亮金黄色粗体文字 `+30s (快速)` + 纯白时间进度
   - 倍速调节：时钟测速图标 + 蓝紫色/金黄色文字 `播放速度 1.5x` / `切换倍速 2.0x` / `恢复正常速度 1.0x`
   - 逐帧微调：帧微调图标 + `上一帧` / `下一帧` + 精确时间进度
   - 复制当前帧：剪贴板图标 + `已复制画面到剪贴板` + 分辨率信息
   - 画面截图：相机图标 + `已截图保存` + 分辨率信息
   - 画中画 / 画面镜像翻转：无痕淡入淡出反馈
9. **全生命周期销毁与僵尸UI自动清理**：
   - 彻底解决 Fancybox / 网页悬浮播放器窗口关闭后控制条仍孤立悬挂在页面上方的顽疾；
   - 彻底修复 `!important` 样式优先级覆盖导致的内联 `display: none` 失效 Bug；
   - 彻底解决 ComfyUI 工作流切换、重新渲染节点或关闭浮窗后在屏幕上遗留僵尸控制栏的问题；
   - 结合全局 DOM 级变动监听与 500ms 看门狗，媒体一旦失联或隐藏立即 100% 连根拔起并销毁对应浮层。
10. **零侵入式架构**：
   - 绝不包裹破坏 `<video>` / `<audio>` 在原始页面的 DOM 节点层次；
   - 100% 保持原网页的 CSS 布局、flex/grid 属性与原始媒体尺寸，杜绝变形与移位。
11. **无损真全屏机制**：
   - 全屏时采用视口置顶技术，不移动底层 DOM 节点，零断流风险；退出全屏后 100% 原位无痕恢复。
12. **智能防冲突与输入框保护**：
   - 在网页搜索框、评论区、编辑器打字时，自动禁用所有播放器快捷键；
   - **全面放行 Alt / Meta 组合键**：按下 `Alt+D`（聚焦浏览器地址栏）、`Alt+←` / `Alt+→`（前进后退）以及 Mac `Cmd` 键时，完全不拦截，零冲突交由浏览器原生处理；
   - **智能放行 Ctrl 组合键**：除特定的快进退、音量调节与 **`Ctrl+C` 复制当前帧画面**外，当网页上有选中文本时 `Ctrl+C` 优先放行系统复制文字；`Ctrl+X`（剪切）、`Ctrl+D`（书签）、`Ctrl+F`（查找）等浏览器系统热键 100% 正常使用。
