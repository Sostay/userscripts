# 质感 HTML5 播放器

质感 HTML5 网页播放器，统一主流浏览器播放器外观，支持快捷键（快进快退/音量/全屏/暂停）、左上角高质感 OSD 提示，精准保留原始网页布局和尺寸。

- **Greasy Fork**: [https://greasyfork.org/zh-CN/scripts/554122](https://greasyfork.org/zh-CN/scripts/554122)
- **匹配网址**: `*://*/*`
- **运行策略**: `document-start`

### 🎮 快捷键操作指南

| 按键 | 功能说明 | 左上角 OSD 提示 |
| :--- | :--- | :--- |
| `←` (方向左键) | 微调快退 5 秒 | `⏮ -5s 当前时间 / 总时间` (蓝紫文字) |
| `→` (方向右键) | 微调快进 5 秒 | `⏭ +5s 当前时间 / 总时间` (蓝紫文字) |
| `Shift + ←` / `Ctrl + ←` | **快速快退 30 秒** | `⏮ -30s (快速) 当前时间 / 总时间` (金黄高亮) |
| `Shift + →` / `Ctrl + →` | **快速快进 30 秒** | `⏭ +30s (快速) 当前时间 / 总时间` (金黄高亮) |
| `↑` / `↓` (方向上下键) | 音量调节 (±5%) | `🔊 音量 XX%` (蓝紫文字) |
| 滚轮滚动画面 | 音量平滑调节 (±5%) | `🔊 音量 XX%` (蓝紫文字) |
| `Space` (空格键) | 播放 / 暂停 | `▶ 播放` / `⏸ 暂停` |
| 画面单击 | 播放 / 暂停 (带双击防抖) | `▶ 播放` / `⏸ 暂停` |
| `F` 键 / 画面双击 | 切换无损全屏 | 保持原生节点不重载 |
| `M` 键 | 静音 / 取消静音 | `🔇 静音` / `🔊 音量 XX%` |
